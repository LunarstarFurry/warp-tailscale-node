# Warp exit node

To build `go build -o warp-exit .`

To install to your path `./warp-exit install`, you made need sudo 

To run `sudo warp-exit up`, will provide you a login link to allow access to your tailnet 
Once its up you can see a warp-exit-node as long as you approve it in your tailscale admin 

`warp-exit status` to see what its doing and `warp-exit down` to shut it down.
